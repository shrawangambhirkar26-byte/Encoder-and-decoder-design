# Encoder-and-decoder-design
Encoder and Decoder Design Project

Project Overview

This project demonstrates the design and implementation of Encoder and Decoder digital circuits.

1. Encoder (8 to 3 Encoder)

Description

An Encoder is a combinational circuit that converts multiple input signals into a smaller binary coded output.

Input and Output

- Inputs: D0 to D7 (8 input lines)
- Outputs: Y2, Y1, Y0 (3 bit binary output)

Truth Table

Input| Output
D0| 000
D1| 001
D2| 010
D3| 011
D4| 100
D5| 101
D6| 110
D7| 111

2. Decoder (3 to 8 Decoder)

Description

A Decoder is a combinational circuit that converts binary input into one active output line.

Input and Output

- Inputs: A, B, C
- Outputs: Y0 to Y7

Truth Table

Input| Active Output
000| Y0
001| Y1
010| Y2
011| Y3
100| Y4
101| Y5
110| Y6
111| Y7

Applications

- Digital electronics
- Computer systems
- Memory addressing
- Communication circuits

Tools Used

- Python
- Digital Logic Concepts

Conclusion

Encoder and Decoder circuits were designed and studied to understand the conversion of digital signals in combinational logic systems.
